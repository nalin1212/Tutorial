## 🚀 Getting Started

**Prerequisites:** Python 3.x

```bash
# Clone the repo
git clone <your-repo-url>
cd <repo-folder>

# Run any script
python 11.function.py
```

---

## 📚 Suggested Learning Order

1. **Data Structures** → `1_dict.py` through `4_setmethod_operation.py`
2. **Control Flow** → `5_CONDITONAL.py` → `10_break-and-countinue.py`
3. **Functions** → `11.function.py`
4. **File Handling** → `12.file.py`
5. **OOP** → `13.1.class.py` → `18.super.py`
